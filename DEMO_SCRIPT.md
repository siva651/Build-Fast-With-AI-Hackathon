# ContentPilot AI — 3-Minute Demo Script

## 0:00–0:20 — Problem

“AI can generate marketing copy quickly, but when one campaign is adapted across multiple channels, product facts can drift and unsupported claims can creep in.

ContentPilot is designed around the opposite principle: one authoritative source, every channel, with a source audit.”

## 0:20–0:40 — Product

“Here is the campaign brief. I have a LumaBrew launch with authoritative product facts, audience, tone, and guardrails.

The important part is that the source facts are explicitly separated from the creative brief.”

## 0:40–1:20 — Generate

“Now I generate the content pack.

ContentPilot creates a message map and adapts the same campaign for Instagram, LinkedIn, X, Email, and a Landing Page.”

Click through the platform tabs. Do not read every paragraph.

Point out that the same factual details remain consistent while the format and voice change by channel.

## 1:20–2:05 — Source Lock

“This is the differentiator: Source Lock.

Instead of only asking whether the writing sounds good, ContentPilot checks the combined output against the authoritative source.

It tracks the critical facts it observed and surfaces potential risky wording instead of silently assuming the claim is valid.”

Point to the audit card.

## 2:05–2:30 — Adversarial test

“Now I can run a deliberate Source Lock test.

The test attempts to introduce an unsupported health-benefit claim. ContentPilot is expected to keep that claim out rather than inventing it.”

Click **Run Source Lock test**.

If it passes, say:

“The test passes: the unsupported claim stayed out.”

If it flags a violation, say:

“The audit caught the risky wording. That is exactly the behavior we want surfaced before publishing.”

## 2:30–2:50 — Reliability

“The Gemini API is server-side, so the key never reaches the browser. The server also has a model fallback chain and a clearly labelled demo fallback for temporary model or quota failures.”

## 2:50–3:00 — Close

“ContentPilot turns one trusted campaign source into channel-ready content without losing control of the facts.

One source. Every channel.”
